# Cowork 项目记忆标签页设计

Status: draft（design approved 2026-11-10；implementation not started）

## 背景

项目记忆需要承载用户偏好、项目上下文、关键决策摘要、项目/会话规则和技能。早期 demo 按“约束 / 决策 / 事实”分组，后来按用户要求收敛为项目级分类：

- 工具最大范围是项目级，不做跨项目存储。
- 用户记忆只做项目内记忆，通过导入/导出和全局同步。
- 项目记忆只记录上下文和关键决策摘要。
- 决策记录全文只在 Artifact 资料库查看。
- 规则只保留项目规则/会话规则，遵循规则唯一性。
- 技能分为内置声明技能和用户上传技能。
- 运行上下文后台管理，不进记忆页。

## 设计目标

- 右侧栏只做四类汇总，左侧展示选中类型的详情。
- 上下文记忆用 Markdown，不做时间线。
- 不同记忆类型使用不同详情样式。
- 决策全文留在资料库，记忆只保留摘要和链接。

## 设计过程与决定

### 1. 项目级收敛

跨项目记忆会把权限、来源、冲突和同步引入另一个维度；本版本不做。用户记忆通过导入/导出与全局同步，但记忆本体只在项目内。

### 2. 右侧四类汇总

右栏固定四类：

| 分类 | 内容 |
|---|---|
| 用户记忆 | 偏好 / 反复要求 / 个人约束 |
| 项目记忆 | 项目上下文 / 关键决策摘要 |
| 规则 | 项目规则 / 会话规则 |
| 技能 | 声明技能 / 用户上传技能 |

### 3. 左侧详情，不做时间线

上下文记忆用 Markdown 文档记录“什么时候添加了什么、来源是什么”。例如：

```text
- 2026-11-09 添加：本地优先，不上传云端；不读写 viking://。来源：用户规则
- 2026-11-08 添加：主题使用原生 DSH session。来源：PLAN.md
```

时间线属于活动流，不属于项目记忆。

### 4. 类型化详情

- 用户记忆：卡片
- 项目上下文：Markdown 文档
- 规则：表格
- 技能：技能卡

### 5. 决策摘要与资料库

项目记忆只保存关键决策摘要，并链接到 Artifact 资料库中的决策记录全文。决策记录的 review 和版本不在记忆页完成。

### 6. 规则唯一性

系统、用户、全局规则已有唯一来源；项目记忆只保留项目规则和会话规则，不重复声明。

### 7. 技能

- 声明技能（内置）
- 用户上传技能
- 支持 `/slash` 命令和 Agent 自动调用
- 定义方式与 Anthropic Skills 一致：技能目录 + `SKILL.md`（name / description / 指令），可带资源

### 8. 运行上下文

session / topic / handoff 由后台管理，不作为用户可见记忆分类。

## 界面结构

```text
右侧栏
└─ 项目记忆
   ├─ 总数 + 导入/导出 + 搜索
   ├─ 用户记忆 8
   ├─ 项目记忆 12
   ├─ 规则 5
   └─ 技能 7

左侧
└─ 选中类型的详情
   ├─ 项目上下文.md
   ├─ 添加时间 + 内容 + 来源
   └─ 关键决策摘要 → 资料库全文
```
