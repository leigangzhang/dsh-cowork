工作项交付物信息模型

工作项是用户需要查看、确认、反馈的交付物，指向项目里的已有文件。查看器负责 展示、批注和编辑，参考 规格说明 与 ArtifactAnchor。

1. 记录结构

  • 交付物记录：标题、类型、状态、文件列表、主题归属。
  • 协作记录：评论、批注、回复、附件和版本。
