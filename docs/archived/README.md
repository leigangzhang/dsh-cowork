# 开发归档（V0.1–V0.2）

本目录保存 dsh-cowork V0.1（M0–M4）与 V0.2（M6–M12）已完成阶段的开发过程、探针证据、交接记录与交付结果。归档内容只回答“当时交付了什么、怎么验证、为什么这样决定”，不是当前行为的事实源。

历史记录按语义族分目录：实施交接在 [handoffs/](handoffs)，交付结果与探针结果在 [results/](results)，前置侦察在 [recon/](recon)。下面的阶段表保留原交付顺序，链接指向分类后的位置。

当前事实从这些入口读取：

- V0.1 产品范围、架构与验收：[PLAN.md](../PLAN.md)
- V0.2 主题会话模型重构：[PLAN-V0.2.md](../PLAN-V0.2.md)
- 明确不修的问题与重估条件：[KNOWN_ISSUES.md](../KNOWN_ISSUES.md)
- 验证规则与证据要求：[testing.md](../testing.md)
