本目录保存 dsh-cowork V0.1（M0–M4）已完成阶段的开发过程、探针证据与交接记录。归档内容只回答“当时交付了什么、怎么验证、为什么这样决定”，不是当前行为的事实源。

当前事实从这些入口读取：

- 产品范围、架构与验收：[PLAN.md](../PLAN.md)

- 验证规则与证据要求：[testing.md](../testing.md)
- V0.2 主题会话模型重构：[PLAN-V0.2.md](../PLAN-V0.2.md)
